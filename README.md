# infostyle — редакторский скилл для Claude Code

> A Russian-language editing skill: improve usefulness, clarity and coherence while preserving facts, meaning and the author's voice.

**infostyle** помогает редактировать статьи, письма, посты, лендинги, тексты о себе и компании, инструкции и интерфейсные надписи. Скилл проверяет, что нужно читателю, улучшает структуру и формулировки, убирает лишнее и помогает найти недостающую конкретику.

Метод сверён с **«Пиши, сокращай 2025» Максима Ильяхова и Людмилы Сарычевой**. Ограничения на изменение фактов и порядок работы ИИ — адаптация для скилла. [Карта источников и страниц](infostyle/references/sources.md).

## Что делает

Работает с пользой, ясностью, связностью и чистотой текста. Иногда результат становится короче, иногда — длиннее за счёт нужного объяснения или примера.

| Исходник и известные сведения | Результат |
|---|---|
| «Осуществляем настройку отчётов». Других сведений нет. | «Настраиваем отчёты». |
| «Удобный поиск». В описании указано: поиск заказов по телефону и номеру заказа. | «Найдите заказ по телефону или номеру заказа». |
| «Более 100 клиентов». Точного числа нет. | Сохраняется исходная граница; точное число не придумывается. |
| «Внедрение может уменьшить потери заявок». | Возможность улучшения сохраняется; обещание устранить все потери не добавляется. |

Скилл сохраняет существенные условия, степень уверенности, термины и авторский голос. Стоп-слова проверяются в контексте. Термины, юмор, оценки и эмоциональная пунктуация могут быть уместны.

Редактура предоставленного текста сама по себе не означает независимую проверку всех фактов.

## Установка

Нужна вся папка `infostyle/`, включая `references/`.

**Глобально, для всех проектов:**

```bash
git clone https://github.com/Zoldadt/infostyle-skill.git
mkdir -p ~/.claude/skills
cp -r infostyle-skill/infostyle ~/.claude/skills/
```

**Для одного проекта**, после клонирования репозитория:

```bash
infostyle_project="/путь/к/вашему/проекту"
mkdir -p "$infostyle_project/.claude/skills"
cp -r infostyle-skill/infostyle "$infostyle_project/.claude/skills/"
```

Проверьте установку вызовом `/infostyle` и передайте текст.

## Как пользоваться

Можно вызвать `/infostyle` или попросить проверить текст по инфостилю. Режим определяется запросом.

| Запрос | Результат |
|---|---|
| «Проанализируй текст, пока не переписывай» | Существенные замечания и способы исправления |
| «Отредактируй, сохрани мой голос» | Готовый текст с необходимыми правками |
| «Перестрой текст для другой аудитории» | Новая композиция и подача с сохранением исходных фактов |
| «Исправь только опечатки» | Только исправления опечаток |
| «Дай только итоговый текст» | Текст без редакторского отчёта |

Если нужны объяснения, попросите показать значимые изменения в формате «было → стало». Для нового текста передайте бриф и факты; для шаблона можно явно попросить плейсхолдеры.

Аудиторию, площадку, желаемый тон и обязательные термины полезно указать сразу. Скилл использует доступный контекст и спрашивает, когда пробел существенно влияет на результат.

## Источники метода

Основной источник этой редакции:

**Максим Ильяхов, Людмила Сарычева — «Пиши, сокращай 2025. Как создавать сильный текст».** На титульном листе указан 2024 год; в выходных данных — 4-е издание, «Альпина Паблишер», ISBN 978-5-9614-8714-5.

Другие источники, повлиявшие на первоначальный метод:

- **Корней Чуковский — «Живой как жизнь».**
- **Нора Галь — «Слово живое и мёртвое».**
- **William Strunk Jr. & E. B. White — «The Elements of Style».**
- **William Zinsser — «On Writing Well».**
- **David Ogilvy — «Ogilvy on Advertising».**

Формулировки и учебные примеры скилла самостоятельные. Книга и её извлечённый текст в состав репозитория не входят.
