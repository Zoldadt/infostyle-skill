# infostyle — редакторский скилл для Claude Code

> A Russian-language editing skill for Claude Code: it runs your text through *информационный стиль* — cuts filler, swaps vague evaluations for facts, and rewrites in the reader's world.

**infostyle** — авторский редакторский метод, оформленный как навык (skill) для Claude Code. Даёшь ему текст — он чистит словесный мусор, заменяет оценки фактами, выстраивает структуру и подачу и переписывает **в мире читателя**. Подходит для статей, лендингов, писем, постов, текстов о себе и о компании, объявлений и интерфейсных надписей.

## Зачем

Большинство деловых текстов тонут в воде: «динамичная команда профессионалов», «выгодные условия», «осуществляем реализацию продукции». Читатель не верит и закрывает вкладку. Скилл проходит по тексту и возвращает его к делу — коротко, по фактам, про читателя:

| Было | Стало |
|---|---|
| Очень удобная система | Менеджер собрал воронку за 20 минут без программиста |
| Выгодные условия | Рассрочка на 6 месяцев без переплаты |
| Осуществляем реализацию продукции | Продаём |
| Решение было принято руководством | Руководство решило |
| Более 100 клиентов | 137 клиентов |

Метод: **сначала смысл (польза, структура, синтаксис), потом слова (стоп-слова).** Чистить стоп-слова в тексте, где не решена польза, — мартышкин труд.

## Установка

Скилл — это папка `infostyle/` с файлом `SKILL.md`. Положи её туда, где Claude Code ищет навыки.

**Глобально (доступен во всех проектах):**
```bash
git clone https://github.com/Zoldadt/infostyle-skill.git
mkdir -p ~/.claude/skills
cp -r infostyle-skill/infostyle ~/.claude/skills/
```

**Только в одном проекте:**
```bash
cp -r infostyle-skill/infostyle <ваш-проект>/.claude/skills/
```

Готово. Перезапускать ничего не нужно — Claude Code подхватит навык сам.

## Как пользоваться

Вызови команду и дай текст:

```
/infostyle
```

…или просто попроси: **«проверь этот текст по инфостилю»** / **«перепиши в инфостиле»**. Скилл:

1. диагностирует по категориям (*правило → что не так → как починить*),
2. показывает правки в формате **было → стало**,
3. отдаёт переписанный вариант.

Без фанатизма: подсветка стоп-слов — подсказка, а не приговор. Живой голос и здравый смысл выше формулы.

## Что внутри

Скилл покрывает весь рабочий цикл редактуры:

- **Главный принцип** — текст про читателя и его пользу, не про себя.
- **Слова** — стоп-слова: вводные, усилители, оценки→факты, канцелярит, эвфемизмы, фичеризм, отглагольное, причастия, страдательный залог, неопределённое, однородные.
- **Факты** — один факт на предложение, в мире читателя, свойство + польза.
- **Синтаксис** — субъект и сильный глагол, 1–2 мысли на предложение, порядок слов.
- **Структура** — один абзац = одна мысль, модули, сильная цель, аудитория.
- **Подача и заголовки** — диагональное чтение, акценты, контраст, польза вперёд.
- **Текст о себе · реклама и продукт · текст в интерфейсе · честность · процесс редактуры** — и быстрый чек-лист.

Полный текст — в [`infostyle/SKILL.md`](infostyle/SKILL.md).

## На чём основано (источники метода)

Метод — не изобретение автора, а сборка из того, чему он учился у мастеров редактуры и рекламы. Первоисточники, которые стоит прочитать:

- **Максим Ильяхов, Людмила Сарычева — «Пиши, сокращай».** Современный информационный стиль.
- **Корней Чуковский — «Живой как жизнь».** Откуда пошёл термин «канцелярит».
- **Нора Галь — «Слово живое и мёртвое».** Борьба с канцеляритом в русском тексте.
- **William Strunk & E. B. White — «The Elements of Style».** «Omit needless words».
- **William Zinsser — «On Writing Well».** Ясность и простота в нон-фикшене.
- **David Ogilvy — «Ogilvy on Advertising».** Реклама на фактах и пользе.

Скилл переписан своими словами и со своими примерами: он передаёт **идеи метода** (которые свободны и принадлежат авторам выше), а не их защищённый текст.
